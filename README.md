# Guardian AI Insights

@connector:github:"GitHub API" Build a complete modern web application called:

OSUSUGUARD AI

Project Title:
An Explainable Multi-Source AI Framework for Fraud Detection in Informal Community Savings Groups (Osusu)

PURPOSE

The system helps detect fraud, suspicious transactions, manipulation, missing contributions, payout irregularities, fake records, and financial inconsistencies within informal community savings groups (Osusu).

The system must not only detect fraud but also explain WHY a transaction was flagged using Explainable AI principles.

The application should look like a premium fintech platform comparable to Flutterwave, Paystack, Moniepoint, Stripe Dashboard, or modern banking software.
